# Composants

Portage des sections 04 à 09 du design-system Atrium (Open Design) : chaque spécimen
est le composant réel, extrait des pages — les mêmes classes, les mêmes tokens
`--od-*` de `src/index.css`, les mêmes états. Le CSS de référence vit dans
`src/design-system/atrium.css`, les composants React dans `src/design-system/components/`.

## Boutons

Deux variantes seulement. Le bouton primaire est noir et réservé à l'action décisive
de l'écran ; le secondaire est neutre.
