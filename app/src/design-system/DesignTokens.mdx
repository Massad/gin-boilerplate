# Contrat de jetons

Toutes les palettes ci-dessous sont générées à l'exécution depuis les variables CSS de
`src/index.css`. Le sélecteur de thème de la barre d'outils bascule la classe `.dark`
sur `<html>` : les valeurs affichées reflètent le thème actif, sans redondance de
code.

Ce contrat est le point d'ancrage du futur pont « Open Design » : réémettre les
variables dans le même format suffit à mettre à jour l'ensemble.
